# Сеньор Федот Пулемёт

![Федот](assets/fedot.png)

Злой наставник по заливу для команды медиабаеров (FB, гемблинг США по штатам).
Матерится, ржёт и учит лить как Измаилов, только с депом как у Endless Dream.

## Что умеет

- **Путь** — 12 коротких уроков на реальных цифрах команды (Измаилов, Иван, Endless Dream). После урока — вопросы, карточки встают на повтор.
- **Повтор** — карточки по графику 1 → 3 → 7 → 16 → 35 дней (система Лейтнера). Вспоминаешь сам, потом проверяешь.
- **План дня** — вводишь время, свободные часы, лимит спенда, аккаунты и готовые истории. Федот считает, сколько креативов и кампаний заливать, во сколько, и какие штаты брать.
- **Разбор таблиц** — кидаешь выгрузки Power BI (.xlsx): отчёт по кампаниям (с днями, «с макетом» или «сводные данные») и отчёт по креативам. Федот выдаёт решение по каждому креативу (сумма всех копий): ДУБЛЬ / ДЕРЖИ / РЕЖЬ / ВЫКЛ, сравнивает с лучшими баерами, разбирает штаты, казино и истории. Всё считается в браузере, файлы никуда не уходят.
- **Карта штатов** — куда лить первым, что тестить, где осторожно. Плюс казино и истории, которые тянут.
- **Шпаргалка** — калькулятор решения, лестница, светофор, бюджеты, часы США.
- Голос (озвучка браузера, нужен русский голос в системе; лучше всего в Chrome), режим мата «жёстко / мягко», XP, ранги, серия дней.

## Запуск

Это обычный статический сайт, сборка не нужна.

```bash
# локально
python3 -m http.server 8000
# открыть http://localhost:8000
```

**GitHub Pages:** залей репозиторий → Settings → Pages → Deploy from branch → `main` / root. Через минуту сайт будет на `https://<ник>.github.io/<репо>/`.

## Как выгружать из Power BI

1. «Экспортировать» → **Сводные данные** → XLSX.
2. Перед экспортом раскрой таблицу до объявлений, день оставь в строках.
3. Отчёт по креативам (FacebookNew) тоже подходит.

## Где что менять

- `js/data.js` — бенчмарки баеров, штаты, казино, истории. Обновляй раз в неделю по свежим отчётам.
- `js/course.js` — уроки, вопросы, карточки.
- `js/fedot.js` — аватар, голос, фразы, мат-фильтр.
- `js/analyzer.js` — разбор таблиц и правила решений (`FD.decide`).

Пороги — ориентир по истории команды за сентябрь и 1–18 октября 2026, а не закон. Лимит спенда всегда за тимлидом.
